Answer the natural-language SQL questions in dataset.json using its exact schema and the immutable contract.json. The accepted query.py component is the fixed execution backend. The goal is a better question-to-SQL workflow, not a replacement executor.

Write queries.json as one JSON object keyed by the supplied question IDs. For an allowed read request, the value is exactly {"sql": "SELECT ..."}. For a prohibited mutation or file-access request, the value is exactly {"refused": true}. Preserve the question's requested columns, order, filtering and treatment of missing values. Do not add explanatory text to this JSON artifact.

The controller evaluates the SQL on multiple datasets using a frozen SQLite execution oracle. Development results are available to the workflow optimizer; final held-out questions and their expected answers are not. A workflow receives credit for query behavior measured by this evaluator, not for writing a persuasive report.
